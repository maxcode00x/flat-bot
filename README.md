# Бот поиска жилья — OLX + Otodom → Telegram

Каждые ~10 минут проверяет OLX и Otodom по фильтрам из `config.yaml` и присылает
в Telegram новые объявления с фото, ценой, czynsz, площадью и районом.
Работает бесплатно на GitHub Actions, компьютер включённым держать не нужно.

## Запуск (≈15 минут, один раз)

### 1. Создать бота в Telegram
1. Напиши **@BotFather** → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** вида `7123456789:AAH...` — сохрани его.
3. Открой своего нового бота и нажми **Start** (без этого бот не сможет тебе писать).
4. Узнай свой **chat id**: напиши **@userinfobot** — он ответит числом `Id: 123456789`.

> Чтобы объявления приходили ещё и девушке — пусть она тоже нажмёт Start у бота
> и узнает свой id; в секрет `TELEGRAM_CHAT_ID` впиши оба через запятую: `123456789,987654321`.

### 2. Залить бота на GitHub
1. Зарегистрируйся на github.com (если ещё нет).
2. **New repository** → имя, например `flat-bot` → **Public** → Create.
   - Public — минуты GitHub Actions бесплатные без ограничений. В репозитории видны
     только твои фильтры (город, цена), токен и chat id скрыты в секретах.
   - Если сделаешь Private — бесплатно 2000 минут в месяц, тогда в
     `.github/workflows/flat-bot.yml` поменяй `*/10` на `*/30`.
3. На странице репозитория: **uploading an existing file** → перетащи **все файлы
   из распакованной папки, включая папку `.github`** → **Commit changes**.
   - Если папка `.github` не перетащилась: **Add file → Create new file**, в имени
     напиши `.github/workflows/flat-bot.yml`, вставь содержимое файла → Commit.

### 3. Добавить секреты
**Settings → Secrets and variables → Actions → New repository secret**:

| Name | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | твой id (или несколько через запятую) |

### 4. Включить
1. Вкладка **Actions** → если просит — нажми зелёную кнопку включения workflows.
2. Слева **«Поиск жилья»** → **Run workflow** → Run.
3. Через минуту в Telegram придёт «✅ Начал следить…» и по 3 свежих объявления
   на каждый поиск. Дальше бот сам проверяет каждые ~10 минут и шлёт только новые.

## Как менять фильтры
Открой `config.yaml` на GitHub → карандаш (Edit) → поменяй цифры → **Commit changes**.
Все поля описаны прямо в файле. Самое полезное:
- `price_max` — цена аренды, `total_max` — максимум вместе с czynsz;
- `rooms: [2, 3]`, `area_min: 35`;
- `districts: ["Pogodno", "Śródmieście"]` — только эти районы;
- `private_only: true` — без агентств;
- `url:` — вставить готовую ссылку поиска с olx.pl или otodom.pl;
- `enabled: false` — временно выключить поиск.

## Если что-то не так
- **Ничего не приходит** — Actions → последний запуск → шаг «Проверить объявления»: там лог
  вида `на странице 52, по фильтрам 10, новых 0`. «новых 0» = просто нет новых объявлений.
- **Ошибка в шаге «Сохранить просмотренные» (push denied)** — Settings → Actions → General →
  Workflow permissions → **Read and write permissions** → Save.
- Если поиск 3 раза подряд падает (сайт поменялся или заблокировал запросы), бот сам
  пришлёт предупреждение в Telegram.
- GitHub запускает расписание с задержкой 5–15 минут — это нормально.

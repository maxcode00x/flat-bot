# Бот поиска жилья — OLX, Otodom, Domiporta, Nieruchomosci-online, Gratka/Morizon → Telegram

Каждые ~10 минут проверяет OLX, Otodom, Domiporta, Nieruchomosci-online и Gratka/Morizon и присылает
в Telegram новые объявления по фильтрам каждого пользователя. Языки: русский, польский,
английский, украинский (выбор при /start или кнопкой 🌐). Фильтры выбираются кнопкой **⚙️ Фильтры** прямо в боте.
Работает на GitHub Actions — компьютер включать не нужно.

## Файлы
- `bot.py` — сам бот
- `i18n.py` — тексты бота на 4 языках
- `features.py` — оценка цены, признаки мошенничества, дубли, сообщение владельцу
- `docs/index.html` — страница фильтров (открывается в Telegram, хостится на GitHub Pages)
- `.github/workflows/flat-bot.yml` — расписание запуска
- `seen.json` — появится сам; зашифрован, в публичном репозитории его никто не прочитает

## Секреты (Settings → Secrets and variables → Actions)
- `TELEGRAM_BOT_TOKEN` — токен от @BotFather
- `TELEGRAM_CHAT_ID` — твой ID (админ): сюда приходят предупреждения, если сайт перестал отвечать.
  Пользоваться ботом может любой — у каждого свои фильтры.

## GitHub Pages (нужно для кнопки «⚙️ Фильтры»)
Settings → Pages → Build and deployment → Source: **Deploy from a branch** →
Branch: **main**, папка **/docs** → Save.

## Как пользоваться
1. Actions → «Поиск жилья» → Run workflow — бот пришлёт приветствие с кнопкой **⚙️ Фильтры**.
2. Нажми кнопку, выбери фильтры, нажми **Сохранить фильтры**.
3. При следующей проверке (обычно 10–15 минут) бот подтвердит фильтры, пришлёт
   несколько самых свежих объявлений, а дальше — только новые.
4. Поставить на паузу — там же, переключатель «Поиск на паузе».

## Что умеют фильтры
Квартира / комната / оба · OLX и/или Otodom · город · районы и осидла Щецина ·
цена аренды и итог вместе с czynsz · комнаты · площадь · этаж · тип дома ·
балкон, лифт, гараж, отдельная кухня, кондиционер, терраса, сад, интернет ·
мебель · животные · год постройки · на сколько человек комната · кому сдают ·
только частники · слова-исключения и обязательные слова.

На OLX нет фильтров балкона, кухни и т. п. — их бот ищет в тексте объявления.
Отсекается только явное «нет» (bez windy, brak balkonu, nieumeblowane, bez zwierząt). Если в объявлении
об этом не сказано, оно всё равно приходит со строкой «❔ не указано: лифт, мебель».
Gratka и Morizon — одна база объявлений, поэтому это один источник (только квартиры).
Мебель, животные и «кому сдают» есть только на OLX, год постройки — только на Otodom.

## Что умеет бот
- До 3 профилей поиска у каждого (например, «квартира Pogodno» и «комната в центре»).
- Под каждым объявлением: ❤️ в избранное, 🚫 скрыть навсегда, ✉️ готовое сообщение владельцу
  на польском (по данным из «О себе»), 📍 карта, 🔗 открыть. Список избранного — кнопка ❤️ внизу.
- 📊 Оценка цены: насколько дешевле/дороже средней цены за m² по осидлу/району (считается по
  собранным объявлениям, появляется, когда данных достаточно).
- ⚠️ Предупреждения о мошенничестве: деньги до просмотра, владелец «за границей», ключи курьером,
  без просмотра, оплата через Airbnb/Booking, цена намного ниже рынка.
- 📉 Сообщение, если цена уже присланного объявления снизилась.
- 🔁 Одна и та же квартира с разных сайтов приходит одним сообщением + ответ со ссылкой на дубль.
- 🌙 Тихие часы: ночью бот молчит, утром присылает всё одной пачкой.
